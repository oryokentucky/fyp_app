## 📖 About This Project

This was my Final Year Project and my first real experience with **Flutter** and mobile application development. It's a Shopee-style e-commerce mobile application built to help **local stores launch their own e-business** — giving small retailers a digital storefront without depending on big marketplace platforms.

By presentation day, the app was fully working with features I'm proud of:

- 🤖 **AI Chatbot** — in-app customer assistance
- 💳 **Installment Payments** — flexible payment plans for customers
- ⭐ **Loyalty Points** — reward system to keep customers coming back
- 🛍️ Product listings, cart, and checkout flow

**Tech Stack:** Flutter · Dart · Firebase

---

## 🔄 Why "Revival"?

After starting my internship, I set the project aside — and the final, completed version was unfortunately lost and can't be recovered.

This repository is my mission to **rebuild the app to its former glory**, and push it further with the knowledge and experience I've gained since. What was an ending is now a new beginning.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/oryokentucky/fyp_app.git
cd fyp_app

# Install dependencies
flutter pub get

# Run the app
flutter run
```

> ⚠️ You'll need a Firebase project configured with your own `google-services.json` / `GoogleService-Info.plist` to run the app locally.
